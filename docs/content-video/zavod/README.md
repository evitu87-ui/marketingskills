# Контент-завод: свой, 8 цехов

_Старт 23.11.2026. Свой завод вместо покупки у Павла: всё открыто, правится под себя._

## Принцип

- **n8n (service.aida-oceana.com)** держит конвейер: расписания, таблицы состояния, кнопки в Telegram, публикацию. Папка «Контент-завод».
- **Мозг** (сценарии, редактура) — Claude через ключ Anthropic, который уже есть в n8n.
- **Монтаж** n8n делать не может: на сервере нет запуска команд и ffmpeg. Монтаж идёт в облачной сессии Claude по расписанию или на отдельном сервере рендера (решение в цехе 5).
- Конвейерные цеха — это воркфлоу (жёсткое расписание и шаги). Агент с памятью и свободой решений нужен только там, где есть выбор: сценарист и редактор.
- Человек в контуре один раз: кнопка «одобрить» перед публикацией.
