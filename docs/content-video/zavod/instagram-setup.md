# Два аккаунта Instagram под завод: создание и оформление

_25.11.2026. Аккаунтов и страниц пока нет. Шаги ниже делает Виталий с телефона и с компьютера, это около часа. Названия кнопок у Meta меняются, ориентируйтесь на смысл._

## Что получится

- Два профессиональных аккаунта Instagram: русский и английский.
- Оба в одном бизнес-портфолио Meta (оно у вас уже есть: через него работает WhatsApp).
- Приложение Meta с доступом на публикацию, токены лежат в n8n. После этого собираю цех 7.

## Шаг 1. Создать два аккаунта

1. Почта: два отдельных адреса, по одному на аккаунт (не личный).
2. В приложении Instagram: «Создать аккаунт». Сначала русский, потом через «Добавить аккаунт» английский.
3. Имя пользователя. Проверьте, что свободно, в таком порядке:

| | Русский | Английский |
|---|---|---|
| Вариант 1 | `flatmarketdubai` (как Telegram) | `flatmarket.uae` |
| Вариант 2 | `flatmarket.dubai` | `flatmarket.property` |
| Вариант 3 | `dyachenko.dubai` | `vitaly.offplan` |

4. Сразу включите двухфакторную защиту: Настройки → Центр аккаунтов → Пароль и безопасность.

## Шаг 2. Сделать аккаунты профессиональными

1. Настройки → Тип аккаунта и инструменты → Переключиться на профессиональный аккаунт.
2. Тип: **Бизнес**. Категория: «Агент по недвижимости» (Real Estate Agent).
3. Контакты: рабочая почта и WhatsApp. Адрес не указывайте.

## Шаг 3. Оформить профиль

**Поле «Имя»** (по нему ищут, до 64 знаков):

- RU: `Недвижимость Дубая и Омана · Виталий Дьяченко`
- EN: `Dubai & Oman Off-Plan Property · Vitaly`

**Описание** (до 150 знаков):

- RU: `Недвижимость от застройщика: ОАЭ, Оман, Саудовская Аравия, Катар. Сначала цифры, потом мнение. Подборки объектов в Telegram ↓`
- EN: `Off-plan property in the UAE, Oman, Saudi Arabia & Qatar. Numbers first, opinions second. Project shortlists below ↓`

**Ссылка:**

- RU: `https://t.me/flatmarketdubai`
- EN: страница сайта на английском. Какую ставим, решите вы: `aida-oceana.com` или `oman-realty.com`.

**Фото профиля.** Ваше настоящее фото в деловом образе на тёмно-синем фоне, одинаковое в обоих аккаунтах. В роликах будут и ведущие, и ваш аватар, поэтому лицо бренда в шапке должно быть одно и настоящее.

**Актуальное** (обложки сделаю в стиле паспорта: тёмно-синий, латунь): «Обо мне», «Проверка застройщика», «Районы», «Оман», «Вопросы».

## Шаг 4. Привязать к бизнес-портфолио Meta

1. С компьютера: business.facebook.com → Настройки → Аккаунты → Аккаунты Instagram → Добавить. Войдите в каждый аккаунт по очереди.
2. Страница Facebook. По документации Meta для публикации через «API с входом через Instagram» страница не обязательна. На живом аккаунте я это не проверял. Страница понадобится, если захотите запускать рекламу из этих аккаунтов: тогда создайте одну страницу бренда и привяжите к ней оба аккаунта.

## Шаг 5. Приложение Meta и токены

1. developers.facebook.com → Мои приложения → Создать приложение. Тип: «Бизнес», портфолио ваше.
2. Добавить продукт **Instagram** → раздел «Настройка API с входом через Instagram».
3. В «Роли» добавьте оба аккаунта Instagram как тестировщиков. В каждом аккаунте примите приглашение: Настройки → Приложения и сайты → Приглашения для тестировщиков.
4. В том же разделе нажмите «Сгенерировать токен» для каждого аккаунта. Нужны разрешения `instagram_business_basic` и `instagram_business_content_publish`.
5. Токены в чат не присылайте. В n8n: Credentials → New → **Bearer Auth**. Создайте два: `Instagram RU` и `Instagram EN`, в поле Token вставьте токен. Напишите мне, когда готово.

Пока приложение в режиме разработки, оно публикует только в аккаунты из «Ролей». Проверка приложения Meta для этого не нужна (по документации; уточню на первом тестовом посте).

## Шаг 6. Хранилище для видео

Instagram забирает ролик по открытой ссылке. В n8n уже есть ключ «Timeweb S3». Создайте в Timeweb отдельный бакет, например `zavod-video`, с доступом на чтение по ссылке. Бакет `menaoffplan-media` и медиатеку сайта не используем.

## Первые две недели

Это осторожная практика, а не правило Meta:

- Первые 3–5 постов выложите руками с телефона, по одному в день.
- Не подписывайтесь массово и не рассылайте сообщения.
- Автопубликацию через API включаем после первых ручных постов.

## Про пометку «создано ИИ»

Вы решили публиковать без пометки. Учтите одно: правила Meta требуют помечать реалистичное видео, созданное ИИ, и в API публикации для этого появился отдельный параметр `is_ai_generated`. Meta может поставить метку сама или ограничить показы. Для новых аккаунтов это риск. Решение остаётся за вами, в цехе 7 сделаю переключатель.
