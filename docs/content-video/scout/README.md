# Разведка (цех 1): таблица хуков по ссылкам на рилсы

_22.11.2026. Своя замена «Разведке» из завода Павла: код открытый, правится под себя._

## Что делает

`scout.py` берёт список ссылок на рилсы и по каждому ролику собирает:

- аккаунт, дату, лайки, комментарии, подпись;
- расшифровку речи (faster-whisper), **хук** (фразы, начатые в первые 3,5 с) и **концовку** (последняя фраза, обычно призыв);
- темп: склеек в минуту, слов в секунду, длину.

Итог: `report.md` (таблица, сортировка «лайки + 5 × комментарии») и `data/<код>.json` с полной расшифровкой.

## Запуск

```bash
/usr/bin/python3 scout.py links.txt РАБОЧАЯ_ПАПКА            # скачать, разобрать, отчёт
/usr/bin/python3 scout.py links.txt РАБОЧАЯ_ПАПКА --report   # только пересобрать отчёт
```

- `links.txt`: одна ссылка в строке, `#` начинает комментарий.
- Модель речи: `WHISPER_MODEL` (имя или локальная папка) и `HF_HUB_OFFLINE=1`, если модель уже скачана.
- Видео в репозиторий не кладём: рабочая папка вне репозитория.

## Ограничения

- **Список рилсов аккаунта автоматически не собирается.** Instagram без входа отдаёт страницу входа и после нескольких запросов отвечает 429. Работает только скачивание по прямой ссылке, с паузой 20 с между роликами.
- **Просмотров нет.** Без входа доступны лайки и комментарии.
- Модель `small` ошибается в именах (Nakheel → «Nikhil») и может потерять первое слово под музыкой. Для банка хуков цитаты сверять с роликом.

## Автосбор по аккаунтам: Apify Instagram Reel Scraper (проверено 23.11.2026)

Официальный актор Apify `apify/instagram-reel-scraper` (ID `xMc5Ga1oCONPmWJIa`): 204 тыс. пользователей, 3,07 млн успешных запусков за 30 дней, рейтинг 4,39.

- **Вход:** `username` (логины, ссылки на профили или на рилсы), `resultsLimit` (рилсов на профиль, по умолчанию 25), `onlyPostsNewerThan` (дата или «2 weeks»), `skipPinnedPosts`, `skipTrialReels`.
- **Выход на рилс:** `videoPlayCount`, `videoViewCount`, `likesCount`, `commentsCount`, `timestamp`, `videoDuration`, `videoUrl`, подпись, `ownerUsername`, музыка, 10 последних комментариев. Числа подписчиков нет: выбросы считаем к медиане просмотров аккаунта.
- **Цена (тариф Free):** $0,0026 за рилс + $0,001 за запуск, то есть $2,60 за 1000. Бесплатный кредит $5 в месяц покрывает около 1900 рилсов. 15 аккаунтов × 30 рилсов = 450 рилсов ≈ $1,17.
- **Платные дополнения не берём:** расшифровка $0,048 за начатую минуту (у нас своя, бесплатная), число репостов $0,007 за рилс (только на платных тарифах), скачивание видео с оплатой за мегабайт (качаем сами по `videoUrl` или yt-dlp).
- Домены `apify.com` и `api.apify.com` добавлены в среду. Нужен токен Apify (заголовок `Authorization: Bearer`), в чат и в репозиторий не кладём.

Свой аккаунт Instagram для входа не использовать: риск блокировки.
