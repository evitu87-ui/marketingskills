# Handoff: content-video — Build Kit v1 + пост-стадия (озвучка/плашки/титры)

_Дата: 2026-08-08. Сессия: обсуждение с Боссом видеоконвейера для недвижимости (ОАЭ, Оман, Сауди, Катар, Куала-Лумпур, аудитория HNWI)._

## Контекст проекта

Проект в общем мозге: `agents.projects.canonical_name = 'content-video'` (Контент-конвейер — Видео / Инста / ТикТок). Хендоффы — в `agents.handoffs` (стандарт brief: task_summary / done / blockers / next_step / artifacts).

## Стратегические решения (зафиксированы в чате)

1. **Сам объект недвижимости нейросетью не генерируем** — HNWI-покупатель заметит выдуманный фасад/вид, плюс регуляторика рекламы off-plan (RERA/DLD). ИИ работает вокруг реального материала, не вместо него.
2. **Image-to-video из рендеров девелоперов** (Kling / Runway / Pika) — легальный способ «оживить» брошюры: статичный рендер → 5–10 сек облёта.
3. **Мастер-клип держим чистым** (без текста/голоса) — все языковые и персонализированные версии собираются дешёвой пост-стадией, дорогая генерация Veo не повторяется.
4. **Текст в кадре только монтажом** — в negative prompt Veo обязательно «no text, no captions, no watermarks».

## Build Kit v1 (файл Босса, 20.06.2026)

Замкнутый контур: TG-бриф → Set(parse) → Claude(промпт JSON) → Veo 3.1 через Gemini API (`predictLongRunning`) → Wait/poll/IF → **обязательный** забор MP4 на Timeweb S3 (Gemini хранит ролик всего 2 дня!) → TG-превью с Approve/Reject → Postiz (TG, Reels, Shorts, TikTok, YouTube). Параллельно — Earth Studio «Test Flight A»: облёт здания (180→60 м, дуга +70°, ease in/out), первый кадр = якорь image-to-video.

Ключевое из файла: тесты на `veo-3.1-lite`, финалы на полной модели; model id брать живьём из AI Studio; единственное неподтверждённое место — точный путь к полю с URL готового MP4 в JSON операции (разметить руками на первом прогоне).

## Спроектировано в этой сессии: пост-стадия (между Нодой 8/S3 и TG-превью)

- **Нода 3 расширяется**: Claude одним вызовом выдаёт `veo_prompt`, `negative_prompt`, `vo_script` (скрипт озвучки под длину клипа, язык из брифа ru/en/ar), `plates[]` (2–3 плашки с таймингами: цена, payment plan, CTA).
- **Нода 8.1 — ElevenLabs TTS**: vo_script → MP3; клон голоса Босса, мультиязычность из одного скрипта.
- **Нода 8.2 — сборка**: развилка НЕ РЕШЕНА — (а) ffmpeg на self-hosted (amix + ducking, плашки/титры через ASS) бесплатно, или (б) Creatomate/Shotstack по брендированному шаблону через HTTP (есть интеграция с n8n, платно, дизайн из коробки).
- **Нода 8.3 — финал в S3**: `video-prod/{project}/{timestamp}_final.mp4`; в TG-превью и Postiz идёт эта ссылка, не мастер.
- Субтитры почти даром: текст vo_script уже есть, тайминги из per-character timestamps ElevenLabs.

## Правила материалов (из хендоффа 03.07)

Русскоязычные материалы без англицизмов (переуступка, сдача, доходность, новостройка). Брокер: VITALY DYACHENKO. CTA канала: «Следите за новостями», без имени бренда. Съёмка всегда 4K с безопасным центром кадра (вертикаль режется из горизонтали).

## Дополнение 26.08.2026

- **OmniVoice** (k2-fsa, 9.4k звёзд, Apache 2.0): зирошот-TTS, клон с 3–10 сек, 600+ языков, дизайн голоса словами, Apple Silicon MPS (мак Босса подходит). Решение: Нода 8.1 = взаимозаменяемый TTS-провайдер; старт на ElevenLabs (таймкоды для титров из коробки), OmniVoice — на слепой тест через HF Space демо. Если паритет по качеству — забирает масштаб (бесплатно, локально). Минусы: нет таймкодов (нужен Whisper-alignment), нужен хостинг для n8n, акцент переносится (en — аутентичность, ar — дизайн голоса словами вместо клона).
- **Правило голосов:** клонируем ТОЛЬКО голос Виталия или с письменного согласия владельца. Чужие голоса в маркетинг не идут — юридический риск, в Заливе особенно.
